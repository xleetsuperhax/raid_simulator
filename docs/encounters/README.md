# Encounter Specs

One file per boss (e.g. `boss-01.md`), containing: mechanic list, per-role assignments, timing windows, difficulty-tier deltas, and explicit acceptance criteria (what "correctly implemented" means, testable). This is what gets handed to Claude Code for implementation and what the test cases in `docs/testing/` verify against.
